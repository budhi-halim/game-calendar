Game Calendar

Game Calendar is a personal project for tracking release dates for Honkai: Star Rail, Zenless Zone Zero, and Arknights: Endfield. Its web interface is called Patch calendar.

The calendar displays historical dates, announced updates, and projected future releases using Jakarta dates. Version names and release dates are confirmed independently. Projections are estimates, not publisher announcements.

Open calendar

Optional Google Calendar synchronization

The owner can authorize a local Python script to maintain release events in their own Google Calendar. The integration keeps historical releases and three upcoming releases per game. It uses private, all-day events marked free, with reminders disabled.

Synchronization reads calendar metadata, sharing permissions, and application-managed event records. It updates its own release entries rather than unrelated appointments. Authorization takes place through Google in the owner's browser; the project does not request the Google account password.

The public website does not connect visitors' Google accounts. Opening the calendar does not authorize Google access or create events. The optional integration is configured and run separately by the owner.

Privacy and contact

The privacy policy explains Google data access, local storage, optional automated processing, and removal of access. The terms of use describe the project's personal-use scope and release-date limitations.

For questions about Google authorization or data handling, use the project's support email displayed on the Google authorization screen.
