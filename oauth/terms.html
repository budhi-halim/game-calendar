Game Calendar · Last updated 4 October 2026

Personal project

Game Calendar, whose web interface is called Patch calendar, is a personal game-release planning project. The public calendar can be viewed without Google authorization. Its Google Calendar integration is intended for the owner's account, not as a public account-connection service.

Release information

Future dates may be predictions and can change. Historical records and announcement parsing can contain mistakes. A confirmed version name does not necessarily mean its release date is confirmed. Consult the linked publisher announcements when accuracy is important.

Calendar changes

Authorization is required before the integration can access Google Calendar. A preview can be generated without Google requests. Explicit synchronization or an enabled scheduled workflow can create, rename, reschedule, or remove application-managed entries according to the configured policy. Review the preview and destination before the first write.

Credentials and operation

The owner is responsible for choosing the correct account, protecting credentials, reviewing data changes, and configuring any automated workflow. Do not publish private runtime files or authorization tokens. The privacy policy explains processing and how to remove access.

Availability and affiliation

Continuous operation, exact release-date accuracy, and compatibility with future publisher or API changes are not guaranteed. This is an independent project, not an official product of Google, HoYoverse, HYPERGRYPH, or GRYPHLINE. Game names and promotional artwork remain associated with their respective rights holders.

Contact

For questions about the personal integration, use the support email displayed on the Google authorization screen.
